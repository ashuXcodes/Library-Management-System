# Library Management System (Java)

A console-based Library Management System developed using Java and Object-Oriented Programming.

## Features

- Add Student
- Add Book
- Issue Book
- Return Book
- View Students
- View Books
- View Loan Records
- Automatic Issue Date using LocalDate

## Technologies Used

- Java
- OOP Concepts
- ArrayList
- LocalDate
- VS Code

## Project Structure

src/
├── library
│ ├── domain
│ ├── service
│ └── ui
